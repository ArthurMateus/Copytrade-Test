    How to follow one

    Send its /fomoadd command to the bot. The bot reads that wallet's full 30 days on-chain and applies the same rules; it follows only if they pass and a slot is free. To follow without that check, use /fomofollow with the same wallet.

      The rules (the bot's FOMO rules, unchanged)

      Candidates come from FOMO's 24-hour, 7-day and 30-day leaderboards. FOMO only shows each trader's last 100 swaps, so a trader can be "promising": it passes every rule except the amount of history. Only swaps paid in USDC or USDT count, like in the bot.
